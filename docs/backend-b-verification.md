# 백엔드 B 최종 검증 기록

2026-10-10, Java 21 / Spring Boot 4.0.6 / PostgreSQL 16.15.

## 확인 결과

- 임시 로컬 PostgreSQL에서 Flyway V1~V4 신규 적용 및 재기동 검증 성공.
- JPA ddl-auto=validate 성공.
- 전체 테스트 171개 성공, 실패·생략 0. 이 실행은 CHECKIN_TEST_DB=disposable로 DB 통합 검증을 활성화했다.
- 일반 CI 실행은 DB 통합 검증 21개를 생략하며 기존 테스트와 HTTP 입력·인증 검증을 실행한다.
- IntelliJ build_project 성공, 컴파일 문제 없음.
- bootJar 성공, 실행 가능한 Spring Boot JAR 패키징 확인.
- 실제 HTTP 회원가입·JWT 로그인·내 정보·프로젝트·배정 → 자동 회차 → 조회·제출·동일 요청 재전송·재조회 → 이슈 즉시 해결 → 과거 제출 보존·기록·집계 확인.
- 미인증 401, 잘못된 로그인 401, 잘못된 입력 400 확인.
- 로컬 Swagger는 기존 32개 경로에 B 7개 경로가 추가된 39개 경로다. 체크인 7개 동작과 이슈 2개 동작이 포함된다.
- 공개 Swagger는 확인 시점에 기존 32개 경로로 새 체크인이 아직 배포되지 않았다.
- 원격 main은 확인 시점 7d6bf7b이며 V3/V4 번호 충돌 없음.

## 최종 코드 리뷰

별도 검토자가 권한·동시 처리·시간 경계·대상/기록 보존을 읽기 전용으로 검토했다. 작업 이름 수정 전 회차 생성 누락 1건을 발견해 실제 PostgreSQL 테스트가 실패하는 것을 확인한 뒤 연결 호출을 추가했다. 수정 후 전체 검증을 통과했다. 반복 일정 변경과 종료 전 확정 누락 사례도 추가했다. 미처리된 중요 지적은 없다.

## 구현상 결정과 적용 범위

- 기존 프로젝트의 과거 대상을 추정하지 않고 V4 적용 이후부터 회차를 시작한다. 이전 의무를 소급 집계해야 한다면 당시 데이터에 근거한 별도 전환이 필요하다.
- 개인 기여도를 실제 완료자 데이터 없이 계산하지 않는다. 하위 작업 담당자와 수행자를 같은 사람으로 간주하지 않는다.
- 정수 진행률은 A 계약을 유지한다. 스냅샷에 전체·완료 항목 수도 보존하고 DONE 여부는 실제 항목 수로 판정한다.
- A 엔티티·인증·보안·V1/V2는 유지했다. 승인된 기능과 체크인 연결 호출만 수정했다.
- 실제 프론트 저장소·화면과 공개 서버 데이터는 수정하지 않았다. 프론트 연결 계약은 docs/backend-b-checkin-api.md에 있다.

푸시·PR·수동 머지 및 공개 서버 배포는 아직 수행하지 않았다. README는 main의 별도 문서 커밋 2848321로 갱신했다. 기능 브랜치들은 이 문서 커밋 위로 정리했다.
